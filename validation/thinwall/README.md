# 열 셸 검증

이 자료는 `thinwall-v1` 기본 경로의 실제 계산 결과입니다. 과거 voxel 예제의 저장 결과를 새 결과로 사용하지 않았습니다. `results.csv`에는 각 계산의 요소·절점 수, CAD 중간면 면적, 실제 두께, 셸 부피/질량, 전개도 질량, STEP 체적과의 차이, 20분 온도·수분, 외기/바닥 방열량, 내부 전달 경로, 실행 시간 및 에너지 수지 오차가 들어 있습니다.

## 재현

```bash
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pytest -q
python validate_thinwall.py --phase python
python validate_thinwall.py --phase ansys --host workstation
python validate_thinwall.py --phase report
```

원시 입력·해석 이력·MAPDL 로그는 `jobs/thinwall_study/`에 생성됩니다. Python 해석은 24/12/6/√21/3.5/3/2.5/2/1.5 mm를 사용합니다. ANSYS Student에서는 24/12/6/√21/3.5 mm를 실제 실행합니다. 3.5 mm의 기준 상자는 셸 53,048개와 표면·집중 요소까지 총 106,099개입니다. 더 미세한 ANSYS 비교는 Student의 전체 요소 한도에 걸릴 수 있어 미실행이며 Python 미세 격자 결과와 혼동하지 않습니다.

기준 상자의 내부는 320×320×50 mm입니다. 둥근 모서리 대조군은 내부 크기와 높이를 유지하고 수직 모서리 반경을 내부 57 mm/외부 60 mm로 둔 STEP입니다. 그 DXF는 질량 조건만 맞는 기준 전개도를 재사용한 **열해석 대조군**이며, 둥근 상자를 접어 만드는 실제 전개도가 아닙니다. 따라서 이 자료로 제작 가능한 설계의 우열을 확정하지 않습니다.

## 두께·면적·질량 보존

| 형상 | 중간면 면적 | 두께 | 셸 부피 | 열적 재료 질량 | 셸-STEP 체적 차이 |
|---|---:|---:|---:|---:|---:|
| 기준 | 0.277134 m² | 0.003 m | 0.000831402 m³ | 166.2804 g | −0.006495% |
| 둥근 모서리 | 0.26593564696 m² | 0.003 m | 0.000797806941 m³ | 159.561388 g | −0.005316% |

이 값들은 모든 메시에서 동일합니다. 셸 중간면의 `A*t`와 원래 두꺼운 solid 체적 사이에 남는 작은 차이는 모서리의 셸 근사이며, 격자 변화로 생긴 오차가 아닙니다. 과거 약 −20~+30%의 voxel 체적 진동을 제거했습니다. 전개도 질량은 두 대조군 모두 171.3456 g으로 별도 유지됩니다. 두께를 조정하거나 질량을 격자에 맞추지 않았습니다.

CAD 면적 정규화는 열용량과 면적 적분의 총량을 고정합니다. 정상 평판 저항의 분석해 `R=t/(k*A)`와 직렬 대류 저항을 자동 테스트로 검증합니다. 셸 표면은 표준 얇은 셸 근사에 따라 양쪽 필름에 중간면 면적을 사용합니다. 내·외측 offset 면의 면적 차이와 두께 내 단시간 온도 분포를 그대로 재현하는 3D solid 해석은 아닙니다.

## 수렴 판정

`convergence.json`은 연속 격자 간 온도차, 외기 대비 온도 상승으로 정규화한 상대 차이, 방열량 차이를 기록합니다. Richardson/GCI에는 실제 평균 요소 길이 `sqrt(CAD 면적 / 요소 수)`를 사용하고, 미세→중간·중간→거친 격자의 실제 비율이 조금 다를 수 있는 일반식을 풉니다. 6→3→1.5 mm(Python)와 6→√21→3.5 mm(ANSYS)를 사용합니다. 단조성과 양의 관측 차수가 성립하지 않으면 외삽 값을 만들지 않습니다.

Python의 3→1.5 mm 온도 변화는 기준 0.001076°C, 둥근 모서리 0.001069°C입니다. 최종 1.5 mm 값은 각각 69.335219°C와 69.419574°C입니다. 두 설계 차이는 3/2.5/2/1.5 mm에서 약 0.08435~0.08436°C로 유지됩니다. 수치 격자 변화보다 충분히 큰 차이지만, 아래의 물리 모델 가정과 제작 조건을 독립적으로 검증한 것은 아닙니다.

공간 격자만 수렴해도 시간 오차는 남습니다. 6 mm 고정에서 10/5/2.5초 시간 간격도 실행했습니다. 결과는 JSON의 `*_time_refinement`에 기록되며, 공간 수렴 자료의 온도는 모두 같은 10초 간격으로 비교합니다.

Python 실행 시간은 CAD import·표면 메시·열해석까지, ANSYS 실행 시간은 원격 MAPDL 프로세스의 경과 시간입니다. ANSYS의 로컬 전처리 시간은 별도 열에 제공합니다. Python/ANSYS 내부 시간차를 솔버 성능만의 차이로 해석하지 마세요.

## 자동 검증과 적용 경계

자동 테스트는 실제 직렬 저항 분석해(1.5/3/6 mm), CAD/셸 면적·열용량 보존, 정확한 피자 원 접촉, 공기와 피자의 체적 열용량, 닫힌 모서리·오목한 패널 접합·곡면, 열린 구멍·미지원 적층부 거부, 에너지 수지, 셸 APDL의 두께·인터페이스, 실패한 ANSYS 로그 거부, 순위의 수분 방향/두께 혼합 방지, GCI 분석식을 다룹니다. 기존의 다섯 테스트도 유지됩니다.

여러 판의 중간면은 공유 절점에서 접속하며 겹친 면을 추가하지 않습니다. 유효한 일정 두께 offset으로 표현되지 않는 겹침/탭·내부 리브·비다양체 접합은 3 mm 한 층으로 뭉개지 않고 오류로 중단합니다. 통풍구는 현재의 밀폐 공기 가정에 맞지 않아 거부합니다. 이러한 설계는 명시적인 적층·환기 또는 별도의 보존된 체적 STEP 경로가 필요합니다. 실제 접힘 운동학과 제조 가능성은 이 열모델의 검증 항목이 아닙니다.

## 최종 검증 결과

Python 22건(두 형상, 공간 격자와 시간 간격 변화)과 Windows MAPDL 10건을 실제 실행했습니다. MAPDL 10개 로그 모두 `RUN COMPLETED`, 오류 0건을 확인했습니다. 원시 로그와 소스/입력의 SHA-256, 라이브러리 버전은 `provenance.json`에 기록합니다. 최종 자동 테스트는 기존 5개를 포함해 총 16개 통과했습니다.

| 형상·솔버 | 관측 공간 차수 | Richardson 온도 | 미세 격자 GCI (외기 대비 온도 상승 기준) |
|---|---:|---:|---:|
| 기준 Python | 1.780 | 69.335666°C | 0.001181% |
| 둥근 Python | 1.837 | 69.419992°C | 0.001101% |
| 기준 ANSYS | 1.467 | 69.336605°C | 0.016710% |
| 둥근 ANSYS | 1.595 | 69.420447°C | 0.015137% |

같은 3.5 mm 메시에서 기준 온도는 Python 69.333631°C / ANSYS 69.330277°C, 둥근 온도는 Python 69.418013°C / ANSYS 69.414706°C입니다. 누적 외기+바닥 방열량은 기준 45,380.35 J / 45,388.49 J, 둥근 45,197.24 J / 45,205.22 J로 약 0.018% 이내에서 일치합니다. Python의 최대 에너지 수지 오차는 0.0286 J, ANSYS는 0.000042 J이며 이는 약 45 kJ의 외부 방열량에 비해 작습니다.

6 mm 이하의 공간 격자에서 둥근−기준 온도 차이는 Python +0.084353~+0.084383°C, ANSYS +0.084401~+0.084439°C입니다. 두 설계의 차이는 이번 모델의 공간 격자 오차와 구분됩니다. 더 따뜻한 둥근 대조군은 수분 잔존율도 약 0.1%p 높았으므로, 대회의 온도·바삭함을 동시에 개선했다고 해석할 수 없습니다. 전개도는 같은 것을 사용했으므로 공식 질량 감소도 주장하지 않습니다.
